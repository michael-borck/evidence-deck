# The Evidence Deck — source note

Distilled from two books in the Tessera series
(`/Volumes/Crucial X9/Projects/books/`):

- `prove-dont-persuade/` — "Anyone can demo AI. The edge is proving it works."
  The three release gates (prototype → bounded pilot → production → continued
  operation), evidence vs demonstration, proof brief, evidence dossier, trust
  grid (precision × blast radius), headline accuracy rules, adversarial
  testing, conversation logs.
- `test-the-claim/` — "A policy is a claim. A control is a claim that has
  survived testing." Assurance questions, scope and criteria, the evidence
  matrix, inspect/inquire/observe, triangulation, the rating table (Met /
  Partial / Not met + confidence + limitation + what would change it), the
  defensible Partial.

The fictional teaching company (Tessera, case SDA-2026.1) does not appear in
the deck; the discipline is taught generically, as the books themselves state
it.

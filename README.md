# The Evidence Deck

<p align="center">
  <img src="assets/art/banner.png" alt="The Evidence Deck" width="720">
</p>

Twenty-three cards of evidence discipline for anyone evaluating AI systems,
distilled from *Prove, Don't Persuade* and *Test the Claim*. Free product: no
gate, no capture.

**Live:** https://michael-borck.github.io/evidence-deck/

**Anyone can demo AI. The edge is proving it works.**

## The design

One organic size: 23 cards — Claims (5), Gates (5), Measurement (5), Ratings
(4), Records (4). One card type: why it goes wrong, the move, the line.

## deck/

| File | What it is |
|---|---|
| `evidence-deck-23-cards.md` | The deck, markdown. |
| `evidence-deck-23-print.html` | Print & cut. 4 A4 pages, 8 cards per sheet. |
| `evidence-deck-23-art.html` | Art edition: portrait cards, category vignettes, 6 per A4. |
| `evidence-deck-guide.html` | One-page diagnostic. |
| `evidence-deck-desk-card.html` | Every card, every line — one A4 pin-up. |
| `fonts/` | Domine, Funnel Sans, Nanum Gothic Coding (SIL OFL). |

Art: `assets/art/` holds the steel-and-ledger identity — cover, back, banner and
category illustrations, generated with limn. Prompts and the locked style prefix
are in `assets/art/README.md` and the `.png.json` sidecars.
